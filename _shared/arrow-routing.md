## §1 自动数据流转箭头规格

**只画 3-5 条主流转箭头**，不细化到每个模块：

- 沉淀流：触达层 → 数据层（用户行为沉淀）— **必有**
- 回补流：数据层 → 上层（加工后回补）— **必有**
- 可选追加：外延流（连到层外部，如 CRM、第三方系统）

**箭头视觉规格**：

| 项 | 规格 |
|---|---|
| 形状 | SVG `<path>` cubic bezier 曲线。**绝对不要**直线、**绝对不要**直角拐弯 |
| 颜色 | 中性灰 `#94A3B8`（赛博风用 `#FF00FF`，其他风格按 visual-styles.md 强调色） |
| 粗细 | `stroke-width: 1.5px` |
| 箭头头部 | 用 SVG `<marker>` 定义三角形 |
| 标签 | 贴在曲线纵向那段中段，背景加半透明色块衬底（防止被层背景挡） |
| 标签字号 | 12px / font-weight 500 |

## §2 间隙列路由规则（核心难点）⚠️

**核心约束**：箭头**禁止从任何模块卡片的中间穿过**。这是产生"横穿马路"视觉怪味的根源，必须用以下规则避免。

**适用对象**：所有箭头（自动 + 用户手动添加），无论跨多少层。

### 实现思路

**1. 识别"间隙列"**

每一层的相邻模块之间存在空白间隙（如模块 A 和模块 B 之间有 12-16px 间距），这些间距加上"层左缘"和"层右缘"，都是"间隙列"。箭头可以从间隙列纵向穿过。

**2. 为每条跨层箭头分配一个垂直间隙列**

- 优先选**离源模块和目标模块都最近**的间隙列
- 该间隙列在**所有需要穿过的中间层**都必须真实存在（即各层模块布局允许这个 x 坐标位置始终是空白）

**3. 路径绘制（SVG cubic bezier）**

- **起点**：源模块**底边中心**（向下流转）或**顶边中心**（向上流转）
- 弯向间隙列的 x 坐标（用平滑 bezier 曲线，**不要 90° 直角**）
- 沿该间隙列纵向贯穿所有需要跨越的层
- 弯入目标模块（同样平滑 bezier）

**4. 多条箭头共用同一间隙列时**

水平错位 8-12px（多条平行线并排），并保证标签互不重叠。

**5. 箭头标签位置**

放在**纵向那段**（间隙列内部）的中段。**不要**放在弯折处。

### 示意图

```
触达层:  [模块A]  [模块B]  [模块C]  [模块D]
                                ╲
                                 ╲  ← 沉淀流（在 C 和 D 之间的间隙列向下穿）
                                  │
场景层:  [模块A]  [模块B]  [模块C] │ [模块D]
                                  │
能力层:  [模块A]  [模块B]  [模块C] │ [模块D]
                                  │
                                  ╱
数据层:  [模块A]  [模块B]  [模块C]╱ [模块D]
```

### 绝对禁止

- ❌ 箭头垂直穿过任何模块卡片
- ❌ 直角折线（90° 拐角）
- ❌ 同一间隙列里多条箭头重叠

## §3 起点段 / 终点段必须垂直于模块边 ⚠️

**问题来源**：箭头三角形（marker）的朝向由 SVG path 末段的切线方向决定。如果 path 末段是斜的曲线，marker 会跟着斜——**箭头看起来像从侧面斜着插进模块的钉子**，不精致。

**强制规则**：所有箭头的**起点段和终点段**必须是**纯直线段**（不是曲线），方向必须**垂直于源/目标模块的边**：

- 进 / 出**顶边或底边**（数据流转的常态）：直线方向**纯垂直**（同 x 坐标）
- 进 / 出**左边或右边**（特殊情况，如外延流）：直线方向**纯水平**（同 y 坐标）
- **直线段长度至少 20px**，保证 marker 的切线方向稳定

### SVG path 结构示例

```
M 源点
L 源点垂直偏移20px              ← 强制垂直起点段
C 控制点 控制点 弯折点1           ← 弯到间隙列
L 弯折点2                       ← 沿间隙列纵向走
C 控制点 控制点 终点垂直偏移20px   ← 弯回目标方向
L 终点                          ← 强制垂直终点段（保证箭头朝向）
```

**视觉效果**：箭头三角形和模块边永远保持垂直，没有"斜着插进去"的怪味。

## §4 画布边距与箭头间距规则

| 规则 | 数值 |
|---|---|
| 画布左右各留边距 | **24-32px** |
| 同层级跨度内相邻箭头水平间距 | **≥ 60px** |
| 同一间隙列内多条箭头水平错位 | 8-12px |
| 起点段 / 终点段直线长度 | ≥ 20px |

**为什么画布要留边距**：向外延伸的箭头（推测的虚线、外延流箭头）容易被画布边切掉，留 24-32px 边距保证它们能完整渲染。

**如果间隙列实在不够分配**（5 条流转难以塞下）：**考虑合并相邻流向**——例如把"沉淀:用户对话"和"沉淀:上传文件"合并成一条"沉淀:用户行为/上传"。

## §5 手动添加连接（画线模式）

工具栏 `+ 添加连接` 按钮，点击进入"画线模式"。

### 画线流程

1. **进入画线模式**：工具栏按钮变成 `✕ 取消` 状态，颜色变高亮
2. **激活模块**：主画布所有模块进入"可被选中"状态——hover 时模块边框变实色高亮、光标变 `crosshair`
3. **点击第一个模块（源）**：该模块边框变成主题色实线，模块上浮一个"源"小标签
4. **移动鼠标到目标模块**：实时绘制一条**虚线预览**箭头（从源模块到当前鼠标位置）
5. **点击第二个模块（目标）**：
   - 画出最终曲线箭头
   - 箭头视觉**完全等同**于自动生成的箭头（同色、同弧度、同 marker、同标签字体）
   - 在箭头中段弹出一个文字输入框，自动 focus
6. **用户输入标签文字**：回车确认 / Esc 取消
7. **自动退出画线模式**：工具栏按钮恢复 `+ 添加连接`

### 视觉一致性强约束

**用户加的箭头和自动箭头用户必须看不出区别**。这意味着：

- 用户加的箭头**同样要走间隙列路由**（§2）
- 用户加的箭头**同样要起点段/终点段垂直**（§3）
- 用户加的箭头**同样遵守边距和间距**（§4）

区分只在 DOM 内部：自动箭头加 `class="auto-arrow"`，手动箭头加 `class="user-arrow"`（用于后续支持"恢复自动箭头"功能）。

## §6 删除箭头

- 点击任何箭头（自动 / 手动均可删）→ 箭头中段标签旁浮出小圆形 `×` 按钮
- × 按钮规格：直径 18-20px，圆形，红色背景 `#EF4444`，白色 ×
- hover × 时整条箭头变成红色高亮（给用户"即将删除"的视觉提示）
- 点击 × 即删除
- **自动箭头被删后**：工具栏出现小字提示 `↩ 恢复自动箭头`（淡色，仅在有自动箭头被删时显示）→ 点击把所有删除的自动箭头复原回来（避免误删无法挽回）

## §7 箭头自检（产出含箭头的 HTML 前过一遍）

- [ ] 自动箭头 ≤ 5 条，曲线、有文字标签、标签有半透明衬底防遮挡
- [ ] 所有箭头都从模块之间的"间隙列"穿过，**绝不切穿任何模块卡片**
- [ ] 每条箭头的起点段和终点段都是**纯直线，且垂直于模块边**（marker 朝向正确不歪）
- [ ] 画布左右各留 24-32px 边距，没有箭头被切出画布
- [ ] 同层级跨度内相邻箭头水平间距 ≥ 60px，不拥挤
- [ ] 同一间隙列里多条箭头水平错位 8-12px，标签不重叠
- [ ] 箭头标签放在纵向那段中段，不在弯折处
- [ ] 用户加的箭头视觉等同于自动箭头（颜色、弧度、marker、字体全一致）
- [ ] 用户加的箭头**同样走间隙列路由 + 垂直进出**，不切穿模块
- [ ] 点击任何箭头出现 × 按钮，hover × 时整箭头变红
- [ ] 删除自动箭头后工具栏出现"↩ 恢复自动箭头"提示
