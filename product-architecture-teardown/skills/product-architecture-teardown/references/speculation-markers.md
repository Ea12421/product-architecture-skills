## §1 为什么需要这份文件

teardown skill 的产出经常包含两类内容：

- **实证内容**：用户提供的、官方资料的、web search 搜到的事实
- **推测内容**：Claude 基于公开信息和合理推断的（在文字里标 `[推测]`）

两类内容**视觉上必须明显区分**，让用户一眼分清"这是事实"还是"这是 Claude 的推断"。否则用户可能把推测误当事实，对产品决策造成误导。

**触发标 `[推测]` 的场景**（这部分逻辑在主 SKILL.md，本文件不重复）：
- 反推能力时 Claude 自己猜的能力
- 反推数据时 Claude 自己猜的数据来源
- 任何非用户提供 / 非搜索结果的内容

本文件**只管视觉怎么做**，不管"什么内容要标"。

## §2 推测内容的三重视觉区分（核心规则）

无论选 visual-styles.md 中的哪种风格，推测内容**必须**同时满足下面三重区分：

| 维度 | 规则 |
|---|---|
| **容器边框** | `border: 1px dashed <浅色>;` — 注意是 dashed 不是 solid，颜色比所在层主色**浅 30%** |
| **文字字形** | `font-style: italic;`（斜体） |
| **文字颜色** | 比实证内容**浅一档**（如风格 1 主文字 `#F8FAFC` → 推测 `#94A3B8`） |

**三重叠加**才能让用户一眼分清推测和实证。**只用一种**（比如只用斜体）不够。

### 各风格的推测色推荐值

| 风格 | 实证主文字色 | 推测文字色（浅一档） | 推测边框色 |
|---|---|---|---|
| 1 技术克制 | `#F8FAFC` | `#94A3B8` | 主色 70% 透明（如 `rgba(59,130,246,0.7)`） |
| 2 暖色友好 | `#1F2937` | `#6B7280` | 主色 70% 透明 |
| 3 极简日式 | `#1A1A1A` | `#737373` | `#A3A3A3` |
| 4 暗黑赛博 | `#00FFFF` | `#00CCCC` | 主色 70% 不透明度（保留霓虹感） |

如果架构图里某一层主色不同，按"主色浅 30%"原则各自计算。

### CSS 示例（风格 1）

```css
.module.speculation {
  border: 1px dashed rgba(59, 130, 246, 0.7);  /* 比层主色 #3B82F6 浅 30% */
  color: #94A3B8;                              /* 比 #F8FAFC 浅一档 */
  font-style: italic;
}

.module.speculation .pill {
  font-style: italic;                          /* pill 标签也用斜体 */
  color: #94A3B8;
}
```

### HTML 示意

```html
<div class="module speculation">
  <div class="pill">推荐算法 <span class="badge">[推测]</span></div>
  <div class="content">
    基于公开 demo 反推，疑似使用协同过滤 + Embedding 相似度...
  </div>
</div>
```

## §3 推测的数据流转箭头（虚线版）

推测的数据流转**箭头本身用虚线**，让用户知道"这条流转是推测的"。

| 维度 | 实证箭头 | 推测箭头 |
|---|---|---|
| 形状 | SVG path cubic bezier 曲线 | 同左 |
| 颜色 | `#94A3B8`（或风格强调色） | 同左 |
| 粗细 | `stroke-width: 1.5px` | 同左 |
| **线型** | 实线（默认） | **`stroke-dasharray: 5,5`** |
| Marker（箭头头部） | 三角形实色 | 三角形实色（marker 不用虚线） |
| 标签字体 | 12px / 500 | **12px / 500 / italic**（斜体） |
| 标签前缀 | 无 | 加 `[推测]` 前缀（如"`[推测]` 用户行为回补"） |

### SVG 示例

```html
<!-- 实证流转 -->
<path d="..." stroke="#94A3B8" stroke-width="1.5" fill="none" marker-end="url(#arrow)"/>

<!-- 推测流转 -->
<path d="..." stroke="#94A3B8" stroke-width="1.5" stroke-dasharray="5,5" fill="none" marker-end="url(#arrow)"/>
```

> ⚠️ **箭头的路由规则（间隙列、垂直起终点、画布边距、错位）跟实证箭头完全相同**。见 `arrow-routing.md`。推测的视觉差异只在"线型、文字字形、标签前缀"三处，**不改变路由逻辑**。

## §4 推测内容自检（teardown 产出 HTML 前过一遍）

- [ ] 所有标了 `[推测]` 的内容都用了**虚线边框 + 斜体 + 浅色**三重区分（缺一不可）
- [ ] 推测的容器边框颜色是层主色的浅版本（70% 透明 / 浅 30%），不是默认灰
- [ ] 推测的数据流转箭头用了 `stroke-dasharray: 5,5`
- [ ] 推测箭头的标签加了 `[推测]` 前缀且用 italic
- [ ] 实证内容**没有**误用 italic / dashed 边框（避免视觉混淆）
- [ ] 即使整层模块都是推测的，每个模块仍单独套三重区分（不要图省事用"整层加底色"的偷懒做法）
